# 🎓 UET-Main AI Chatbot Clone

An AI Chatbot dashboard for **UET Lahore / UET** students. 
Ask about sports, admissions, facilities, and general UET queries - all in one place.

Built with **Python + Streamlit**

### ✨ Features
- **Chat Interface**: Ask questions and get instant answers from UET knowledge base
- **Knowledge JSON**: Easy to add new Q&A like sports, library, thank you messages
- **Dashboard UI**: Clean `dashboard.py` for running in browser
- **Lightweight**: No login, no database. Just `knowledge.json`
- **Git Ready**: Already pushed to GitHub

### 🛠️ Tech Stack
| File | Purpose |
| --- | --- |
| `dashboard.py` | Main Streamlit app UI |
| `uet_chatbot.py` | Chatbot logic / AI response handler |
| `knowledge.json` | Q&A knowledge base for UET |
